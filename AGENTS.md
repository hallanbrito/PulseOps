# Instruções aos agentes — PulseOps / Método C.H.

1. Leia `docs/PROJETO.md`, `docs/STATUS.md`, `docs/CH/PROTOCOLO_AGENTES.md` e a Issue/Fatia W autorizada antes de alterar código.
2. Registre baseline SHA, branch, escopo, executor/modelo e nível de autonomia C.H.
3. Não interprete pedido vago como autorização para merge, deploy, uso de segredos, custo ou operação destrutiva.
4. Trabalhe em branch curta/worktree isolada; execute build/testes e entregue evidências verificáveis.
5. Toda entrega de agente termina em Draft PR + RUC; integração depende de decisão humana explícita.
6. Nunca versionar credenciais, tokens, connection strings reais ou dados privados.
